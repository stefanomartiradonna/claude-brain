# Fonti Emily Segal (da leggere online)

Le fonti sono pubbliche. Non c'è una copia integrale nel repo privato: si leggono online al momento dell'uso, così restano aggiornate. Non tenerne copie nei repo.

**Come si leggono per intero.** WebFetch restituisce solo riassunti: non basta. Per i post di Nemesis usa l'API pubblica di Substack, `https://nemesisglobal.substack.com/api/v1/posts/<slug>` (lo slug è la parte finale dell'URL), e leggi il campo `body_html`. Salva i file temporanei nella scratchpad della sessione. Per i PDF di K-HOLE scarica il file nella scratchpad e leggilo con Read.

Se Nemesis pubblica un nuovo post utile, aggiungi una riga qui e, se cambia il metodo, una nota in `metodo-segal.md`.

Archivio del Substack: https://nemesisglobal.substack.com/archive
